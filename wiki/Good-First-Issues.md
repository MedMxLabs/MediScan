## Difficulty labels

| Label | Meaning |
| --- | --- |
| `difficulty: easy` | One area, clear acceptance criteria |
| `difficulty: medium` | Needs familiarity with an app layer |
| `difficulty: advanced` | Infra, queues, E2E, cross-cutting |

## Tips

1. Comment on the issue before starting (avoid duplicate work)
2. Read [`CONTRIBUTING.md`](https://github.com/MedMxLabs/MediScan/blob/main/CONTRIBUTING.md)
3. Keep PRs focused — one concern per PR when you can
4. Ask questions in the issue thread; maintainers would rather unblock you early
